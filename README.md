# .NET Console Projects

A collection of C# / .NET console applications built while deepening my OOP and backend fundamentals. Each project is a standalone solution; open the `.sln` file in Visual Studio or run it with `dotnet run`.

## Projects

### EventManagementSystem
Console system for managing events, venues, organizers, attendees and tickets, with reporting. Layered structure: Models, Services, Data and Reports.

### EmployeesTracker
Console app for tracking employees, built around core OOP concepts.

### Student-Tracker
Console app for managing student records.

### Project-E-Commerce-oop
Console e-commerce simulation with users, products, carts and orders, plus pluggable payment methods (cash, credit card, PayPal) behind an `IPayment` interface.

## Tech

`C#` `.NET 8` `OOP` `SOLID basics`
